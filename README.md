# SmartClinic+

SmartClinic+ is a healthcare management system project developed for
SENG205 Software Engineering.

The project focuses on appointment management, smart queueing,
patient records, laboratory information, notifications and clinical
workflow management.

## Project Artefacts

This repository contains:

- UML and system design diagrams
- SmartClinic+ Hi-Fidelity Figma prototype screens
- Prototype testing and QA evidence
- Project documentation

## Prototype

The Hi-Fidelity prototype was developed in Figma. The tested patient
flow includes:

Login → Dashboard → Book Appointment → Confirmation → Dashboard

Dashboard → Queue Status → Dashboard

## Current Scope

The project currently demonstrates system design and an interactive
Hi-Fidelity prototype. Backend database, security and concurrency
functions are proposed for future implementation and are not presented
as completed functionality.
